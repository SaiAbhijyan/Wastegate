# Fable-Mode — phases and skeptics

Phases: understand → design → implement → adversarial review.
- Understand: restate the task, read the relevant code, list unknowns.
- Design: pick one approach; note the alternative you rejected and why.
- Implement: small verified steps.
- Review: a skeptic tries to refute each finding and each claim of "done". Keep only findings that survive.
- The token budget is a hard cap. When it runs out, stop and report what is unresolved; escalate only that slice.
- This is a process, not a quality claim.
