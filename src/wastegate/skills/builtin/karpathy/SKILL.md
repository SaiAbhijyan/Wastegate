# Karpathy — surgical and verified

- List your assumptions before editing; flag any you cannot check.
- Prefer the simplest code that is obviously correct over clever code.
- Touch only the lines the task needs. Do not reformat, rename, or "improve" unrelated code.
- For a bug: reproduce it first, find the root cause, fix that, and show the reproduction now passes.
- Verify with a command whose output you actually read, not with confidence.
