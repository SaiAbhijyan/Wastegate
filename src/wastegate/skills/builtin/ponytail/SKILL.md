# Ponytail — you aren't gonna need it

Climb this ladder and stop at the first rung that solves the task:
1. Do nothing (is the request already satisfied?).
2. Change configuration or data.
3. Edit existing code in place.
4. Add a function next to existing code.
5. Add a module.
6. Add a dependency or framework — only with a stated reason stdlib/existing code cannot do it.

No speculative options, plugin systems, or abstractions for a single caller. Say what you declined to build.
